# shutaMzala Launch Caption Toolkit

A ready-to-use caption bank for launching shutaMzala on Instagram, TikTok, Facebook, and YouTube.

## Brand positioning

> **shutaMzala helps guests collect, share, and relive the photos from an event in one beautiful gallery.**

Core promises to repeat consistently:

- No guest app download
- No guest account required
- Guests upload directly from their phones
- QR code and event link sharing
- One live gallery for everyone’s memories
- Useful for weddings, birthdays, baby showers, parties, and corporate events

## Before posting

Replace these placeholders when relevant:

- `[EVENT TYPE]` — wedding, birthday, baby shower, party, corporate event
- `[EVENT NAME]` — the event name
- `[HOST NAME]` — host or organiser name
- `[LINK]` — profile link or event link
- `[NUMBER]` — number of photos, guests, or memories
- `[CITY]` — location

Do not promise features that are not enabled for the specific account or event. Use “memories” and “photos” interchangeably, but keep the language warm and simple.

## 15. Voice guidelines

Use:

- Warm, simple, and human language
- Short sentences and clear benefits
- “Guests” and “hosts” instead of technical terms
- “Shared gallery” instead of “content repository”
- “Add your photos” instead of “upload assets”
- Emotional moments supported by practical instructions

Avoid:

- Overpromising permanent storage
- Saying guests never need a link or QR code
- Technical upload/storage language in public captions
- Too many hashtags
- Generic claims such as “the world’s best event platform”
- Posting only product features without showing the emotion behind the event
